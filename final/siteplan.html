Project Overview

This site plan provides the design, content, structure, and development plan for the Grand-Bassam Cultural Heritage and Tourism Guide. The website will be developed using semantic HTML, CSS, and JavaScript.

The goal is to create a responsive, accessible, and informative website that helps visitors discover the history, culture, and important heritage attractions of Grand-Bassam, Côte d'Ivoire.

Site Name

Grand-Bassam Cultural Heritage and Tourism Guide

This name clearly identifies both the location and purpose of the website. It was selected because the site focuses on introducing visitors to Grand-Bassam's history, culture, heritage sites, and tourism opportunities.

Site Purpose

The purpose of this website is to provide an informative and easy-to-use guide to Grand-Bassam's cultural and historical heritage. The site will introduce visitors to the city, highlight important historical and cultural attractions, and provide useful information for people interested in exploring Grand-Bassam.

The website will include images, dynamically generated attraction information, interactive features, and a visitor form. JavaScript will be used to retrieve and display attraction data, manage interactive components, and store visitor preferences.

Target Audience

  • Tourists planning to visit Grand-Bassam.
  • People interested in Côte d'Ivoire's history and culture.
  • Local residents interested in Grand-Bassam's heritage.
  • Students and researchers interested in the city's history.

Typography

Playfair Display

Playfair Display will be used for the website title, headings, and major section headings. Its traditional appearance supports the historical and cultural theme of the project.

Open Sans

Open Sans will be used for paragraphs, navigation, buttons, forms, and general interface content. It provides a clean and readable appearance on different screen sizes.

JavaScript Functionality

Requirement Planned Implementation
Fetch API Attraction information will be retrieved from a local JSON file using the Fetch API.
Try...Catch Asynchronous requests will use try...catch error handling so errors can be handled appropriately.
Dynamic Content At least fifteen attraction items will be dynamically generated from the data source. Each item will display at least four data properties.
Modal Dialog Visitors will be able to open a modal containing additional information about an attraction.
Local Storage Local storage will save an appropriate visitor preference on the user's device.
DOM Manipulation JavaScript will select and modify DOM elements and respond to user events such as clicks, changes, and form submissions.
Array Methods Methods such as map(), filter(), or forEach() will be used to process attraction data.
Template Literals Template literals will be used to construct dynamic HTML content.
ES Modules JavaScript will be organized using ES modules to improve code organization and maintainability.

Responsive Design

The website will be responsive on mobile, tablet, and desktop screens. On small screens, navigation links will be placed behind a hamburger menu. On larger screens, navigation links will appear horizontally.

CSS Grid, Flexbox, flexible images, and media queries will be used to support different screen sizes and prevent horizontal scrolling. The site will support a minimum viewport width of 320 pixels.

Accessibility

  • Semantic HTML elements will be used.
  • Images will include meaningful alt text.
  • Headings will follow an appropriate hierarchy.
  • Forms will use descriptive labels.
  • Interactive elements will support keyboard use.
  • Color contrast will be tested.
  • Modal dialogs will have accessible controls.
  • Links and buttons will have meaningful text.

Images

Images will represent Grand-Bassam's historical buildings, cultural attractions, streets, and coastal environment. Images will be optimized for web use and will maintain their intrinsic aspect ratios.

The loading="lazy" attribute will be used for appropriate images to improve page performance. External images and information will be acknowledged on the attribution page.

HTML Form

The Visitor Guide page will include an HTML form that allows visitors to provide information about their interests.

  • Visitor name.
  • Email address.
  • Preferred attraction category.
  • Visit interests.
  • Additional comments.

The submitted form information will be displayed on form-action.html. This page will not count as one of the three primary website pages.

SEO and Metadata

  • Each page will have a unique and descriptive title.
  • Each page will have a unique meta description.
  • Each page will include an author meta tag.
  • Open Graph metadata will be included.
  • A consistent favicon will be used.
  • Semantic HTML will be used throughout the site.

Testing Plan

HTML Validation

The W3C Markup Validator will be used to identify HTML errors.

Accessibility

WAVE will be used to identify accessibility problems.

Performance and SEO

Google PageSpeed Insights and Chrome DevTools Lighthouse will be used to test performance, accessibility, best practices, and SEO.

Color Contrast

WebAIM Contrast Checker will be used to verify sufficient color contrast.

Browser Testing

The website will be tested in multiple browsers and on different screen sizes.

JavaScript Testing

Browser DevTools will be used to check for JavaScript runtime errors.

Project Video

A 3–5 minute demonstration video will be recorded showing how the required JavaScript features were implemented. The video will demonstrate the data integration, dynamic output, and asynchronous functionality using a try...catch block.

The completed video will be uploaded to a public video-hosting service and linked in the footer of each website page.

Sources and Attributions

External images, information, and other resources used in the project will be acknowledged on an attribution page. The attribution page will be linked from the footer of the home page.
